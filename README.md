# ATS Resume

Minimalist ATS-friendly resume web application built with Next.js, TypeScript, and Tailwind CSS.

Designed for software engineers who want:
- clean architecture
- semantic HTML
- print-friendly layout
- recruiter-friendly formatting
- scalable frontend structure

---

## Tech Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS

---

## Features

- ATS-friendly single-page resume
- Responsive layout
- Print/PDF optimized
- Semantic HTML structure
- Reusable React components
- Type-safe resume data architecture
- Clean and maintainable codebase
